# Security

Please report security problems privately, never in a public issue, pull request or Discord
channel. Email **security@mistysys.com** or use GitHub's private vulnerability reporting on this
repository (Security › Report a vulnerability).

Include what you found, the steps to reproduce it, the version or commit you tested, and the impact
you expect. We will acknowledge the report and keep you informed until it is fixed. Please give us a
reasonable time to ship a fix before you disclose it.

Scope and exclusions are the same as for the
[desktop app](https://github.com/misty-org/misty/blob/main/SECURITY.md).
